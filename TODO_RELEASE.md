# GreenMafia — TODO до публикации в App Store

Обновлено: 27 октября 2026. Цель v1: офлайн-помощник отдельного ведущего для 5–20 игроков, один iPhone, русский и английский. Маршрут: надёжная веб-версия → iOS через Capacitor → закрытый TestFlight → публичный релиз.

`[x]` означает реализовано и проверено указанным способом. Проверка кода не заменяет проверку на iPhone. Публикация, покупки и создание аккаунтов выполняются отдельным согласованным шагом. Сервер, аккаунты игроков и мультиплеер в v1 не требуются.

## Контрольные точки

| Этап | Условие перехода |
|---|---|
| P0 — сохранность партии | Нет тихих ошибок записи; восстанавливаются фаза, черновик голосования и таймер; секреты скрываются при сворачивании; оригиналы повреждённых сохранений остаются доступны |
| P1 — продукт для незнакомого пользователя | Новичок самостоятельно проводит учебную партию; данные можно экспортировать, восстановить и удалить; проверены RU/EN и доступность |
| P2 — iOS / TestFlight | Подписанная сборка устанавливается на iPhone, работает офлайн с первого запуска; пройдена матрица устройств и прерываний |
| P3 — App Store | Пройдены предыдущие этапы, подготовлены сведения Apple и поддержка; нет открытых ошибок, ведущих к потере данных или раскрытию ролей |
