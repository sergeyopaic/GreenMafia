# Ассеты GreenMafia

Готовый комплект от 26.10.2026:

- `roles/`: семь иллюстраций WebP 1024×1536 (включая `don.webp`) и векторная рубашка. Иллюстрации созданы встроенным image_gen; точные промпты сохранены в `generation-prompts.json`.

  Для защиты от угадывания роли по свечению экрана яркость карт выравнивается при отображении (`RoleArt.tsx`); исходные иллюстрации не изменены.
  Портреты показываются целиком (`contain`, привязка к верхнему краю), без обрезки головы при изменении высоты подписи или экрана.
- `stamps/`: девять прозрачных SVG-штампов 1024×512 с вариантами RU/EN. В каждом встроен Rubik Dirt; лицензия OFL — `RUBIK-DIRT-LICENSE.txt`. Ответы комиссару и дону в ночном интерфейсе показываются обычным крупным текстом на тёмной панели, без бумажной подложки и анимации штампа; файлы прежних ответов остаются в комплекте.
- `textures/`: бумага и картон WebP 1254×1254, созданы image_gen. Зернистое сукно удалено: главная и ночная игра используют гладкий зелёный градиент, ночные панели — градиент зелёных поверхностей.
- `audio/sfx/`: 11 оригинальных процедурных WAV-сигналов, 44,1 кГц, моно, 16 бит. Чужие аудиозаписи не использованы. Машинка пока не звучит в интерфейсе; ночью звуки действий запрещены общей политикой.
- `app/public/assets/brand/`: векторная эмблема и три согласованные иконки PWA.
- `app/public/print-kit.html`: пять листов A4 с номерами 1–20 для складывания и лист с общей памяткой. Открывается из правил, работает офлайн.

Повторное создание: `npm run sounds --workspace app`, `npm run graphics --workspace app`, `npm run print-kit --workspace app`. Для иконок: `npm run icons --workspace app` (Python + Pillow). Скрипт `prepare-generated-art.py` только кодирует выбранные PNG в WebP, не меняет композицию; исходные PNG остаются в локальной папке image_gen. Приложению нужны только файлы внутри проекта.

Уже существующие иконки ролей и интерфейса остаются векторными компонентами. Конверт, печать и газета оформлены кодом; отдельные растровые картинки для них не требуются. Фоновая музыка, голос ведущего и финальные иллюстрации отложены. Старый `make-placeholder-icons.mjs` хранится как исходный генератор прототипа; текущая команда `icons` его не вызывает.

Положите файл сюда с указанным путём — приложение подхватит его само, заглушка исчезнет.
Расширение можно любое из перечисленных: картинки — `webp`, `png`, `jpg`, `svg`; звуки — `mp3`, `ogg`, `m4a`, `wav`.
Полное описание и требования — `GAME_DESIGN.md`, §17.

| Путь (без расширения) | Что | Размер |
|---|---|---|
| `roles/civilian` … `roles/maniac`, `roles/don`, `roles/back` | Арт карт 7 ролей и рубашка. Без текста: подпись роли рисует приложение. | 1024×1536 |
| `icons/roles/<роль>` | Одноцветные иконки ролей (SVG, красятся в цвет текста) | 96×96 |
| `stamps/killed`, `stamps/exiled`, `stamps/case-closed` | Штампы «УБИТ», «ИЗГНАН», «ДЕЛО ЗАКРЫТО» (PNG с прозрачностью) | 1024×512 |
| `stamps/alibi`, `stamps/checked-mafia`, `stamps/checked-clean`, `stamps/no-answer`, `stamps/checked-commissar`, `stamps/checked-not-commissar` | «АЛИБИ», «МАФИЯ», «НЕ МАФИЯ», «НЕТ ОТВЕТА» | 1024×512 |
