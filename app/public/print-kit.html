Краткая памятка для живой игры в мафию

Перед партией

  1. Раздайте карточки с номерами — можно случайно. Номер — только метка игрока; в приложении у каждого тот же номер, что на карточке. Речи идут по порядку посадки за столом.
  2. Ведущий не играет. Роль смотрит только её владелец; после раздачи телефон возвращают ведущему.
  3. Ведущий объявляет состав ролей, правила первой ночи, раскрытие ролей выбывших, алиби и регламент речей.

Ночь

Все закрывают глаза. Роли просыпаются по команде ведущего и показывают цель без слов. Обычный порядок: любовница → комиссар → доктор → мафия с доном → дон → маньяк. К кому пришла любовница, тот этой ночью хода не делает. Действуют только роли, предусмотренные партией.

Не прислушивайтесь к телефону и не подглядывайте. Ведущий выдерживает одинаковые паузы, в том числе для выбывших ролей, если включены фиктивные пробуждения.

День

Ведущий объявляет итоги ночи. Затем — последние слова, обсуждение по очереди и выставление кандидатов. Говорите в свой ход и соблюдайте таймер. Выбывшие не подсказывают живым.

Голосование

Показывайте голос по команде ведущего. Порядок при ничьей, возможность воздержаться и действие алиби определяются настройками партии. Итог объявляет ведущий.

Эта памятка не заменяет выбранные правила. Точные ограничения ролей доступны в приложении: «Меню ведущего → Правила этой партии».
