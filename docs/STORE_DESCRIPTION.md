# Описание магазина — рабочий текст для v1

Позиционирование соответствует знакомству внутри приложения. Это черновик для STORE-07, не опубликованные метаданные. Перед подачей проверить текст по финальной iOS-сборке, особенно офлайн-работу и сохранность данных. Публичное имя и условия официальной сборки утверждаются в STORE-01 / STORE-11.

## Русский

GreenMafia помогает ведущему проводить живую мафию за общим столом. Соберите 5–20 игроков и отдельного ведущего — для всей компании нужен один телефон.

Подготовьте состав, настройте правила и раздайте роли с телефона или своими картами. Во время партии приложение подсказывает реплики, ведёт таймеры, помогает выбрать допустимую цель ночью, считает голоса и определяет победителя. Ошибочный ход можно отменить.

Добавляйте игроков по имени, смотрите историю партий и статистику. Профили игроков и партии хранятся на устройстве; участникам не нужно регистрироваться. Установленное приложение работает офлайн. Интерфейс доступен на русском и английском.

## English

GreenMafia helps a host run in-person games of Mafia around one table. Gather 5–20 players and a separate host — one phone serves the whole group.

Choose the composition, adjust the rules and deal roles on the phone or with your own cards. During the game, the app provides lines to read aloud, runs timers, helps select valid night targets, counts votes and determines the winner. A mistaken action can be undone.

Add players by name and view game history and statistics. Player profiles and games stay on the device; participants do not need to register. The installed app works offline. The interface is available in English and Russian.
